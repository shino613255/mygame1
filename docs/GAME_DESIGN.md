# BREAK TACTICS — ゲーム仕様・現行実装

更新日: 2026-10-27
状態: Phase 1・Phase 2完了、Phase 3実装中。数値は初期検証値。

## 1. ゲーム概要

- Unity 2023.2.22f1 / C# の2Dターン制RPG。
- Townで職業を選択し、Questの階層を進み、1対1の戦闘と成長選択を繰り返す。
- 顔・左右の手・脚・腹を狙う。本体HPと部位HPは別管理、腹は破壊不能。
- 中核は、敵の攻撃予告を読み、部位破壊・封印・妨害・弱点・体勢崩しで戦況を変えること。

## 3. Phase 3の現在の範囲

- 戦闘後は取得可能な報酬から異なる3候補を表示し、1つだけ取得。選択時に3ボタンを無効化し、付与・階層進行を一度に限定する。
- 基本成長は1.2倍。戦士=最大HP/AT/DEF、魔法使い=最大HP/MAG/DEF、バーサーカー=最大HP/AT/最大MP。最大MPは増分だけ現在MPを加算する。
- 特殊報酬はクエスト中に各1回。取得後の抽選対象から除外し、次戦へ保持、新クエスト開始で初期化。
- 生命吸収: 新規の破壊可能部位破壊で最大HP5%回復。上限・同部位の重複防止あり。
- 集中攻撃: 同一敵・同一部位の有効連続命中で部位ダメージ1.0→1.2→1.4倍。本体・反射量を増やさない。
- 精密射撃: 今回以前から存在するローカル実装を保持。今回新規追加はしない。
- 3職と固有9技能・共通5技能、新敵3体の9技能を追加。詳細は [設計書](BREAK_TACTICS_Classes_Skills_Enemies_v1.md) と [実装報告](PHASE3_CLASS_EXPANSION_REPORT.md)。
- 戦士の戦技習得・ガード・狙い・雄叫びは戦闘限定。クエスト報酬と分離する。
- 全3職でボス前HP/MP全回復。通常戦や各ターンの自動回復は追加しない。
- 選択式の所持スキルは、旧技能・共通技能を含め各職合計6個以内。既存4枠のページ送りで各2ページに表示する。所持から外した技能アセットは保管する。
- 名前・説明はTMPで描画3行以内、文字サイズ30以上。MP/CDも30の別欄へ表示する。スキルボタンは620×300、ページ送りは230×90。広い画面は2列、狭い画面は1列スクロールとし、既存4枠のページ送りを維持する。詳細は [大型UI報告](SKILL_UI_LARGE_REPORT.md) を参照する。
- VFXは既存素材を使用し、攻撃命中時は選択部位、自己補助・回復は使用者に表示する。不成立・選択のみ・攻撃ミスでは命中VFXを出さず、戦闘終了・交代時に破棄する。技能効果の計算は変更しない。
- 2026-10-27の技能選定・説明文・VFX参照・試験結果は [UI・技能整理・VFX報告](SKILL_UI_LOADOUT_VFX_REPORT.md) を参照する。
- 非ボス階2に魔導監察官・護符の巡礼者、階3に新敵3体を追加。既存4階と最終階の騎士王を保持。

## 4. 現在の数値と資料との差異

- カウンター: 実際の本体HP減少量×1.7。毒・反射・自傷はガード軽減の対象外。
- ファイヤー: 既存SkillDataのcritBonus=0.05、QuestのplayerCritRate=0.02で会心率7%。依頼資料の「確定会心」と違うため、今回無断変更しない。
- 王の重撃: ローカル威力300・2ターン構え。資料の230へ戻さない。
- 毒: 3ターン、最大HP5%、CD4。75%以下で戦術解禁、50%以下で初回特殊行動、重撃解禁35%を保持。
- 既存敵の能力・部位HP・弱点倍率、Mageの能力値と旧技能自体の数値は保護する。所持技能は旧技能を含め合計6個以内とし、外した技能アセットも保持する。
- 提案数値は完成バランスを保証しない。実装済み範囲、素材の代替、描画と試験の限界を実装報告に記録する。

## 5. 実装・検証の扱い

- BattleManager=進行、AI=選択、SkillExecutor=効果、データ=定義、補助クラス=状態。
- SkillIdは追加技能の識別子。既存enumの番号を並べ替えない。
- アセットは対象版UnityのAPIで作成・更新し、GUIDを再利用する。Unity・Packagesを更新しない。
- Unityコンパイル、EditMode、PlayMode、自動描画画像、手動プレイを区別して報告する。
- 今回の3職・技能・新敵の作業で停止する。別の特殊報酬・装備・ダンジョン等は追加依頼を待つ。
